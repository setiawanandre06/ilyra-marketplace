# Ilyra Marketplace

Part of the **Ilyra** ecosystem — a platform for automated vendor price monitoring and multi-marketplace product synchronization.

## Features

- 🔍 **Price Monitor** — automatically track vendor product prices from Shopee
- 📊 **Export to Excel** — download price data with custom mapping & formulas
- 🔄 **Marketplace Sync** — sync products & prices to Shopee, Tokopedia, and TikTok Shop
- ⚡ **Scalable** — built with Celery + Redis to handle 1000+ products

## Tech Stack

- **Framework:** Django 6.0.4
- **Task Queue:** Celery + Redis
- **Database:** PostgreSQL
- **Scraping:** httpx + asyncio
